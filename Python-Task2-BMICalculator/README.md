# BMI Calculator

A desktop-based BMI Calculator built using Python and Tkinter as part of the Oasis Infobyte Python Programming Internship.

## Features

* Enter weight in kilograms
* Enter height in meters
* Calculate BMI instantly
* Displays BMI value up to two decimal places
* Shows BMI category
* Input validation and error handling
* Clear button to reset the fields
* Clean and user-friendly graphical interface

## BMI Categories

* Underweight: BMI below 18.5
* Normal: BMI 18.5 - 24.9
* Overweight: BMI 25 - 29.9
* Obese: BMI 30 and above

## Technologies Used

* Python
* Tkinter

## How to Run

1. Make sure Python is installed.
2. Open the project folder.
3. Run:

```bash
python bmi_calculator.py
```
