# Random Password Generator

A secure and user-friendly Random Password Generator built using Python and Tkinter as part of the **Oasis Infobyte Python Programming Internship**.

## Features

- Custom password length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Secure random password generation using Python's `secrets` module
- Password strength indicator
- Copy password to clipboard
- Clear button
- Input validation and error handling
- Ensures at least two character types are selected

## Technologies Used

- Python
- Tkinter
- `secrets`
- `string`

## How to Run

1. Make sure Python is installed.
2. Open the `Python-Task3-RandomPasswordGenerator` folder.
3. Open a terminal in the project folder.
4. Run:

```bash
python random_password_generator.py
```

## How It Works

1. Enter the desired password length.
2. Select the character types you want to include.
3. Click **Generate Password**.
4. The application creates a secure random password.
5. Check the displayed password strength.
6. Use **Copy** to copy the password to the clipboard.
7. Use **Clear** to reset the fields.
