# To-Do Web App

A modern and responsive To-Do Web App built as part of the **Oasis Infobyte Web Development & Design Internship**.

The application helps users create, organize, edit, complete, and delete daily tasks.

## Features

- Add new tasks
- Add tasks using the Enter key
- Display tasks in separate Pending and Completed lists
- Mark tasks as completed
- Move completed tasks to the Completed Tasks list
- Edit existing tasks
- Delete individual tasks
- Display pending task count
- Display completed task count
- Show task timestamps
- Clear all completed tasks
- Save tasks using browser Local Storage
- Tasks remain available after refreshing the page
- Input validation for empty tasks
- Empty-state messages for both lists
- Responsive design for desktop and mobile devices
- Clean and modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Local Storage API

## How to Run

1. Download or clone this repository.
2. Open the `WebDev-L2-ToDoWebApp` folder in VS Code.
3. Open `index.html` using a browser or Live Server.
4. Add tasks and start managing your to-do list.

## How It Works

- Enter a task in the input field and click **Add Task**.
- New tasks appear under **Pending Tasks**.
- Use the checkbox to mark a task as completed.
- Completed tasks automatically move to **Completed Tasks**.
- Click **Edit** to modify a task.
- Click **Delete** to remove a task.
- Tasks are automatically saved in Local Storage.
- Refreshing the page does not remove saved tasks.
